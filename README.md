# MCI — Métodos Computacionais Intensivos

Repositório dos trabalhos da disciplina de Métodos Computacionais Intensivos (Estatística).

## Estrutura

```
MCI/
├── dados/       # bases de dados (brutas e tratadas)
├── scripts/     # códigos em R / Python
├── notebooks/   # Jupyter / R Markdown / Quarto
├── figuras/     # gráficos gerados
└── relatorio/   # relatório final (LaTeX / Quarto / Word)
```

## Tópicos da disciplina

- Geração de números pseudoaleatórios
- Métodos de Monte Carlo
- Bootstrap e Jackknife
- Testes de permutação
- MCMC (Metropolis-Hastings, Gibbs)
- Algoritmo EM
